# 错题复习调度小工具

面向高中错题整理的本地单页小工具：录入错题后按掌握度和复习间隔安排复习顺序，生成今日待复习清单。

## 运行方式

无需安装环境、无需联网后端。直接用浏览器打开 `错题复习调度.html` 即可使用；数据保存在浏览器本地存储（localStorage），可一键导出 CSV。

## 功能

- 录入：科目、知识点、错因类型、题目简述；
- 归类：按科目、知识点、错因打标签，支持按科目和错因筛选；
- 调度：按掌握等级与上次复习时间计算下次复习日期；
- 今日清单：到期待复习错题按掌握等级、复习日期排序；
- 记录：复习后标记“已掌握 / 仍薄弱”，更新掌握度；
- 导出：一键导出 CSV，作为项目原始记录。

## 调度规则

掌握等级 1—5，对应复习间隔（天）：1、3、7、15、30；达到 5 级归档为已掌握。

- 复习后标记“已掌握”：等级 +1，按新等级间隔安排下次复习；
- 标记“仍薄弱”：等级 −1，回到 1 天间隔；
- 今日清单：未归档且到期的错题，等级低的优先，再按复习日期早的优先。

## 口径说明

- 间隔重复是已有学习思路，本工具的规则是针对高中错题场景做的调整，不宣称发明了新的记忆算法；
- 界面呈现不是创新点，归类规则与复习调度规则才是设计重点；
- 页面内初始为示例数据，正式申报前需替换为本人真实试用记录。
